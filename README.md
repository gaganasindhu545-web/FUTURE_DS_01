# FUTURE_DS_01

## Data Science & Analytics Task 1
### Business Sales Performance Analytics Dashboard

## Project Overview
This project analyzes business sales data to identify revenue trends, top-performing products, and profitable regions using data analytics techniques.

The goal is to help businesses make better decisions using data insights.

## Tools Used
- Power BI
- Microsoft Excel
- Data Analysis

## Key Analysis Performed
- Revenue trends over time
- Sales by category
- Sales by region
- Top 10 products by revenue

## Key Insights
- Technology category generates the highest sales.
- The West region contributes the most revenue.
- A small number of products generate a large portion of total sales.

## Business Recommendations
- Focus marketing on top-selling products.
- Increase investment in high-performing categories.
- Improve strategies in lower-performing regions.
